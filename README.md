# ❤ Smart Heart Attack Prediction with Online Appointment Booking System

## 🧠 Overview
The *Smart Heart Attack Prediction with Online Appointment Booking System* is a full-stack AI-powered web application that predicts the risk of a heart attack based on medical parameters and allows users to book online appointments with nearby or best doctors.  
This system bridges the gap between healthcare prediction and appointment management — providing users with instant health insights and easy access to doctors.

---

## 🚀 Features

### 🔹 AI / ML Module
- Predicts the probability of a heart attack using trained machine learning models.
- Developed using Python (Scikit-learn / Logistic Regression / Random Forest).

### 🔹 Backend (Spring Boot)
- Handles APIs for prediction, appointments, authentication, and feedback.
- Connects to the ML model via REST API or local integration.
- Manages users, doctors, and appointments using a MySQL database.

### 🔹 Frontend (React.js)
- Responsive user interface built using React and Bootstrap.
- Separate dashboards for users and doctors.
- Features include prediction form, appointment booking, doctor list, and reviews.
